This project is an interactive Power BI dashboard developed to analyze PhonePe transaction data across multiple financial services.
The dashboard helps visualize transaction performance, failed transactions, service-wise analysis, and monthly trends using dynamic charts, KPI cards, slicers, and DAX measures.

Total transaction volume analysis
Monthly transaction growth trends

Service-wise performance comparison
